# SIDM — Sistema de Inteligencia de Disponibilidad Médica

App de optimización de rutas para visitadores médicos en Medellín.

## Stack
- **Frontend:** React (web responsive)
- **Backend:** FastAPI + Python
- **DB:** PostgreSQL via Supabase
- **Deploy:** Railway

## Estructura
- `/backend` — API REST FastAPI
- `/frontend` — UI React del visitador

## Setup
Ver `backend/.env.example` para variables de entorno requeridas.
